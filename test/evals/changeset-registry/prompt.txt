plugins/data.json is the source of truth for the plugin endpoints, and it has changed.

For every plugin with "enabled": true, update capabilities/<name>.go so Name, Kind, Endpoint and Timeout match the data, and regenerate plugins/registry.go so it lists exactly the enabled plugins: sorted by name, one "name": "kind" row each. A disabled plugin is not registered and its page must not change. Do not reformat, reorder or re-indent anything else.

Work from the files as they are: do not create, modify or delete any file other than those edits, and leave no scratch files behind.

Then run python3 verify.py and make sure it passes.
