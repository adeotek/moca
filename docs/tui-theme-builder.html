Add to your config

The colors set above map one-to-one onto moca's tui.theme roles (§3.5 · §4). Paste the block below into your user config, ~/.config/moca/config.jsonc, merging it into the existing "tui" key — or into .moca/config.jsonc inside a trusted project, which wins per field (moca asks once on first open). A key you leave out keeps its built-in default.
